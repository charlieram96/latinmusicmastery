Design notes

  • Drums = circles (congas), accessories = rounded squares (cowbell, jam block, etc.)
  • Each shows its piezo number + surface name
  • On hit: green glow + scale up + "HIT!" text (flashes for ~150ms)
  • Mic level bar shown for congas (future technique detection)
  • "Ready" button proceeds to exercise start (replaces calibration flow for PlaySense)
