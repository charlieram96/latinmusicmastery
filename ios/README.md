# Latin Music Mastery — iOS

Native SwiftUI student app (iPhone + iPad, iOS 17+).

## Prerequisites

- Xcode 17+ (Xcode 26 recommended)
- `brew install xcodegen swiftlint`

## Setup

```sh
cd ios
xcodegen generate
open LatinMusicMastery.xcodeproj
```

Select the `LatinMusicMastery` scheme and run on a simulator or device.
